# portfolio
Overview
This is a personal portfolio website created to showcase my skills, projects, and contact information. The website highlights my work in web development and provides links to my social profiles.
The portfolio is designed as a responsive single-page website with sections for introduction, skills, projects, and contact details.
Features
Responsive portfolio layout
About section with personal information
Skills section displaying development skills
Projects section showcasing sample works
Contact section with email and phone information
Social media links (LinkedIn, GitHub, Instagram)
Technologies Used
HTML5
CSS3
JavaScript
Boxicons (icon library)
ScrollReveal (animation library)
